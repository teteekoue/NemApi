Configuration

Onglets fournisseurs, modèles et paramètres généraux du proxy.

Onglets fournisseurs

Choisis l'onglet navigateur à utiliser pour chaque service. Pas de basculement automatique vers un autre fournisseur.

Paramètres

Comportement général du proxy (mode classique).

Streaming (SSE)
Réponses en flux pour les clients qui ne précisent pas stream.
Auto-configuration
Associe automatiquement le premier onglet détecté de chaque fournisseur.
Nouvelle discussion à chaque requête
Ouvre un nouveau chat pour chaque requête : tout le contexte est renvoyé, sans empilement dans l'UI web. Désactivé par défaut (la discussion web persiste) ; une intégration d'agent active l'ignore de toute façon.
Markdown premium
Lit le markdown d'origine de la réponse (React / presse-papiers / HTML→MD), sans clic physique.
Arrêter les jobs
Annule toutes les requêtes en attente ou en cours.
Tu utilises un agent de code (Qwen Code, Nemesis…) ? Active son intégration dans Intégration agents IA : une seule discussion web, un contexte géré, des appels d'outils natifs. Ces intégrations ignorent « Nouvelle discussion à chaque requête ».

L’API

Le proxy parle OpenAI. Rien d'autre.

Le corps de la requête est strictement OpenAI : model, messages, tools, stream. Aucune variable propriétaire (fresh_chat n'existe plus). L'agent se déclare par un en-tête HTTP, que tous les clients savent envoyer.
