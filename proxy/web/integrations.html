Intégration agents IA

Chaque agent de code a son mode : une seule discussion web, un contexte, des appels d'outils. Tant qu'une intégration est désactivée, NemApi garde son comportement classique : la requête entière est tapée dans le chat web, à chaque fois.
NemApi reconnaît l'agent à chaque requête : en-tête X-NemApi-Agent (recommandé), sinon User-Agent, sinon prompt système. Le corps de la requête reste strictement OpenAI — aucune variable propriétaire. Une intégration activée ne s'applique qu'aux requêtes de son agent : les autres clients (Chat test, scripts, autres outils) restent en mode classique.

Aucune discussion attribuée.

Un agent qui ne rouvre jamais de discussion en garde la propriété : les requêtes suivantes, même sans signal, restent dans son mode. C'est ce qui permet à Nemesis (qui n'envoie son prompt système qu'une fois) de continuer dans la bonne discussion.

Autres agents

La liste s'agrandira au fil des versions.

Chaque nouvel agent (Cline, Claude Code, Codex CLI, Aider…) aura sa propre intégration, désactivée par défaut.

En attendant, un agent non listé fonctionne en mode classique : active « Nouvelle discussion à chaque requête » dans Configuration pour éviter que le contexte s'empile dans le chat web.
